# Native Plugin

This directory contains the native RE_Kenshi/KenshiLib source for Traders
Refuse Irrelevant Items.

The active project is:

`toolchain/KenshiLib_Examples/TradersRefuse`

Build it with the normal KenshiLib plugin toolchain: Release, x64, Visual C++
`v100`, KenshiLib, and Boost 1.60. See the root README for the local helper
scripts.
